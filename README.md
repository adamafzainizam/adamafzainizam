## What I've built

**[draftdrill](https://github.com/adamafzainizam/draftdrill)** ([live](https://draftdrill.vercel.app)): practise technical drawing and get marked. You draw on a snapping grid and it tells you exactly what you got wrong. Five topics and 50 exercises, in English and Bahasa Melayu, with 691 tests behind it. The source is private because it holds every answer key, so the repo linked here shows how it works with diagrams and a launch video.

**[Campus Marketplace](https://github.com/adamafzainizam/campus-marketplace)** ([live](https://gmicmp.vercel.app)): a buy, sell and rent board for GMI students and staff. Google sign-in restricted to campus accounts, photo uploads, real-time messaging and a moderation queue. There's a [written case study](https://github.com/adamafzainizam/campus-marketplace/blob/main/docs/case-study.md) of the decisions and the bugs that only appeared in production.

**[Ohrin](https://github.com/adamafzainizam/Ohrin)**: a local Python/ML tool for guitarists and producers who learn by ear. Loop and slow a passage, see what changes, and get cautious instrument, pulse and chord candidates. It ships with a model card that says what the model has and hasn't been measured on.
